# 한신대학교 경기캠퍼스 전체 부지 조감도

기존 Babylon.js 전체 화면과 녹색·베이지 시각 언어, 16개 건물 외관과 내부 상세를 유지하면서 전체 부지와 외부 공간을 함께 읽을 수 있도록 정교화했다. 확장 기획 32개 항목과 3D 고도화 42개 항목의 탐색·제작·검토·공개·복구 흐름을 연결한 로컬 풀스택 플랫폼이다. 실제 학교 자료와 실기기가 필요한 항목은 준비 조건과 미검증 상태를 표시한다.

## 실행

전체 기능의 Vercel 배포는 [Vercel + Turso 배포 절차](docs/vercel-deployment.md)를 따른다. 정적 화면과 서버리스 API를 함께 배포하고 기존 SQLite 자료는 별도 비공개 사본으로 이전한다.

Windows에서는 `start.cmd`를 더블클릭한다. Node.js 22.22.3 이상이 필요하며 최초 실행은 의존성 설치와 빌드를 수행한다. 브라우저 주소는 **http://127.0.0.1:8765/** 이다.

```powershell
npm.cmd ci --ignore-scripts
npm.cmd run build
npm.cmd run dev
```

빌드 후 `index.html`을 직접 열 수도 있다. 로컬 Babylon.js를 사용해 화면이 외부 CDN이나 지도 API를 호출하지 않는다. 최초 설치와 별도 출처 수집에는 네트워크가 필요하다.

관리자 주소는 **http://127.0.0.1:8765/admin.html** 이다. 별도 터미널에서 `npm.cmd run admin:create`를 실행해 계정·역할·캠퍼스 범위·숨김 비밀번호를 입력한다. 기본 계정은 없다. editor/reviewer의 캠퍼스 범위는 `hanshin-gg`이다. 정적/file 실행에는 서버 저장·관리 기능이 없으며 서버 실행 시 `var/campus.sqlite`가 생성된다.

## 반영한 기능

- 전체 부지 조감도, 정사영 위에서 보기, 자유 탐색
- 지형을 따르는 안내 경계와 낮은 대비의 주변 지면
- 운동장·테니스장·야외극장, 주차 구역, 공원·연못, 출입구
- 기존 도로·보행로·짧은 연결 구간·계단과 추정 수목
- 기존 16개 건물의 공식 안내 마커 정렬과 상세 외관 보존
- 건물명·번호·별칭 검색, 선택 정보와 기존 내부 상세
- 카메라 방향에 맞는 북쪽 표시, 정사영 화면의 동적 거리 막대
- 경계·수목·이름·등고선 표시, 지형 강조 배수
- 반응형 조작 패널, 키보드 탐색, WebGL 오류 시 문자 대체
- 출처·확인 수준 안내, 건물명·북쪽·출처를 포함한 PNG 저장
- 영구 공간 ID, 캠퍼스·건물·층·공간·출입구 관계와 항목별 출처/확인 날짜
- 목적·층·공용 시설 검색, 같은 공간의 3D·2D·문자 탐색
- 즐겨찾기·최근 장소·수동 시간표, 가상 투어, 공유 링크·QR·화면 복원
- 현장 검증 자료만 사용하는 경로 엔진과 운영기간 만료 표시
- JSON 자료 검증·변경 비교·복수 캠퍼스 전환, 자급형 GLB 모델 교체 계약
- 기본 부지 우선 표시·개별 상세 로딩·실패 재시도·품질 조절
- 비공개 오류 제보·사진·접수 조회, scoped 관리자·검토·승인·공개판 복구
- 설정한 HTTPS 공급자 가져오기·초안 검토, 공개 API·허용 iframe 출처
- 공개 자산만 검증해 저장하는 오프라인 다운로드·삭제, 한국어/영어 UI
- SQLite 마이그레이션·온라인 백업·감사 기록·지표, 컨테이너와 CI 설정
- 이용 목적별 표시·같은 시점의 자료판 비교·측정·운영 주제·층 형상 검증·VR 조작 설정
- 원본 삼각형을 보존한 16개 조감도 GLB, 거리별 전환·선택 우선 로딩·자원 예산·실제 장면 진단
- 자료·모델 파일을 고정하는 불변 공개 묶음, 승인판의 기본/선택/전체 오프라인 저장
- 실제 IFC 선택 변환·공개 공간 검수·근거 자료 AI 어댑터·현장 기준점 AR 정합 계약

건물이나 목록을 선택하면 상세 위치로 이동한다. 내부 상세를 닫으면 이전 시점으로 복귀한다. 자유 탐색은 이동 키와 마우스로 조작하며 자세한 조작은 화면의 안내를 따른다.

## 개발 검증

```powershell
npm.cmd run lint
npm.cmd run typecheck
npm.cmd run test
npm.cmd run build
npm.cmd run check:generated
npm.cmd run test:browser
```

브라우저 테스트는 최초 한 번 `npx.cmd playwright install chromium`을 실행한다. 데이터 생성·출처 수집 명령은 `evidence/README.md`를 따른다. 외부 조회 실패를 수집 성공으로 처리하지 않는다.

`src/data`는 자료와 생성 데이터, `src/domain`은 좌표·공간 계산, `src/scene`은 렌더링, `src/ui`는 조작과 상세 화면, `src/bootstrap.ts`는 통합을 담당한다. 모델 원본 TS와 브라우저 JS는 빌드로 동기화한다.

SQLite 마이그레이션 3개가 첫 실행에 순서대로 적용된다. 공개 정적 산출물은 `dist/`이며 풀스택 실행에는 서버 코드와 별도 영속 DB가 필요하다. 실제 학교 API·측량 경계·실내 평면·현장 접근성·학교 정밀 GLB/IFC·다른 학교 자료는 미확보/미연결이다. 선택 Python 도구를 사용하는 실제 IFC 선택 변환과 WebXR 기준점/독립 검수점 AR 정합은 구현했다. 검수된 현장 앵커는 미등록이며 실기기 AR/VR·컨테이너/CI 실행·공개 배포는 미검증이다. 기존 공개판의 봉인된 런타임은 새 빌드로 변경되지 않으므로 최신 앱을 승인판 오프라인 묶음에 반영하려면 새 자료/자산 버전으로 검토·승인·공개해야 한다. OSM 파생 공간 데이터는 © OpenStreetMap contributors / ODbL 1.0을 표시한다. 학교 원문 PDF·HTML·삽화 이미지와 사진은 배포하지 않는다.
