# 공간 자료와 검증 상태

`official-campus-markers.json`은 2026-10-07 한신대학교 공식 캠퍼스투어 HTML에서 직접 추출한 지도 안내 마커 15개다. 좌표는 건물 중심의 측량값이 아니다. `hanshin-campus-tour.html`에는 이 추출에 필요한 원문 부분만 보존했다.

공식 2026학년도 정시 모집요강 PDF 38~39페이지의 경기캠퍼스 조감 삽화를 내려받아 렌더하고 직접 확인했다. 운동장·트랙, 테니스장, 야외극장·관람석, 주차 29·30·31, 한신공원과 연못, 정문·동문·서문이 확인된다. 관찰한 픽셀 좌표와 자료 출처는 `campus-map-digitization.json`에 있다. 삽화는 정사영상이나 측량도면이 아니며 외곽·높이·원근법에 오차가 있다. 시설 폴리곤은 가까운 안내 마커의 좌표에 등록한 개략 구획이다. 거의 일직선인 기준점은 안정적인 전체 등록으로 대체한다. 표시 면적은 공식 부지 면적이 아니다.

로컬 검토 원본인 `hanshin-2026-admissions.pdf`, `campus-map-page38.png`, `campus-map-page39.png`, `campus-map-page40.png`와 원문 HTML은 앱 공개 배포 파일에 포함하지 않는다. 앱에는 출처 링크와 사실 추출·추정 공간 데이터만 포함한다. 공식 사진도 재배포하지 않고 원문 링크를 제공한다.

`legacy-spatial-snapshot.json`은 기존 프로젝트의 지도 기반 범위, 2026-05-11 OSM 도로·보행로 기록, 진입 방향과 지형 추정값을 보존한 것이다. OSM way ID와 반올림된 모델 좌표는 기존 affine 변환을 역으로 적용해 WGS84 좌표로 복원한 뒤 동일한 지역 미터 좌표로 투영했다. 원본 OSM node ID가 없으므로 등급 분리·접근 권한·현행 연결 상태는 미검증이다. OSM 유래 공간 데이터에는 **© OpenStreetMap contributors / ODbL 1.0** 출처와 이용 조건을 유지해야 한다. <https://www.openstreetmap.org/copyright>

최신 OSM 조회는 Overpass HTTP 504·406, 보조 서버 타임아웃, OSM API HTTP 429로 실패했다. 최신 원본을 확보했다고 표시하지 않는다. 수집 도구는 제한된 타임아웃과 두 서버만 사용하고 실패 기록을 남긴다. 공적 도면, 지적도·소유 경계, 최신 항공사진·정사영상, 정밀 DEM과 실제 건물 footprint·높이는 확보하지 못했다.

기존 모델의 배치 네 점으로 등록한 좌표를 독립된 나머지 공식 안내 마커 11개에 비교하면 RMS **123.59m**다. 조감 삽화 전체 등록의 독립 마커 RMS는 **64.84m**다. `spatial-verification.json`에 개별 오차, 독립 검증점, 미확보 항목을 기록한다. 오차가 큰 기존 배치는 확정 좌표로 사용하지 않고 건물 중심을 공식 안내 마커로 직접 재배치한다. 외형·지형·출입 방향·시설 외곽은 계속 추정 상태로 표시한다.

`site-plan.js`의 안내 영역은 기존 지도 기반 범위와 표현한 건물·시설을 함께 포함하는 추정 외곽이며 계산 면적은 **149,181.50㎡**다. 법적·지적·도시계획시설 경계는 자료가 없어 `null`이다. 기존 참고값 190,636㎡나 주차 457대를 폴리곤 면적·실제 주차대수로 강제 적용하지 않는다.

새 체크아웃의 오프라인 재생성은 **`node scripts/build-site-plan.mjs`**다. 커밋된 `official-campus-markers.json`, `campus-map-digitization.json`, 출처 기록 및 기존 공간 데이터에서 생성하며 로컬 HTML·PDF·PNG나 네트워크 연결이 필요하지 않다. 원문 해시·기준일·수집 실패·미검증 상태를 유지하고 새 수집을 성공했다고 가정하지 않는다. 추출 좌표 또는 필수 출처 해시가 누락되면 목 자료를 만들지 않고 실패한다.

공식 안내 마커를 실제로 다시 수집하려면 **`node scripts/collect-site-evidence.mjs`**를 실행하고 수집 원문을 검토한 뒤 **`node scripts/build-site-plan.mjs --extract-markers`**를 실행한다. 명시적인 추출 모드는 성공한 HTML 수집 기록과 SHA-256이 일치하는 원문을 요구한다. OSM 조회 실패는 종료 코드 2와 `collection-manifest.json`에 기록되며 이 경우에도 성공한 공식 HTML 수집 기록이 있으면 마커 추출은 가능하다. 최신 OSM 수집이 성공하면 별도 원본을 검토한 뒤 기존 복원 도로·외곽 추정과 교체해야 하며 현재 생성기는 기존 복원 기록을 자동으로 최신 원본이라고 승격하지 않는다.
