# 3D 검수·실기기·캠퍼스 인수 프로토콜

자동 단위 검사, 합성 IFC/XR fixture, 데스크톱 소프트웨어 WebGL 및 모바일 viewport 검사는 실제 학교 측량, 스마트폰, 헤드셋, 장애 당사자 또는 외부 사용자 인수를 대신하지 않는다. 아래 기록은 실제 수행한 날짜/자료판/기기/담당자/결과가 채워질 때 인수 증거가 된다. 미실시 상태를 통과로 기록하지 않는다.

## 공간·자료 검수

1. 자료 소유자가 원본·사용 권리·기준일·법적 경계 종류와 고도 기준을 확인한다.
2. 모델 제작자가 단위·위축·원점·회전·공개 공간 매핑·통계·SHA를 제출한다.
3. 제작에 쓰지 않은 독립 검수점 3개 이상과 수평/수직 허용 오차로 잔차를 확인한다. 허용 오차는 자료 소유자가 용도별로 정한다.
4. 건물 실루엣·출입구·층·공간·관찰 충돌을 자료와 같은 시점에서 확인한다. 근거 없는 항목은 estimated/unverified로 남긴다.
5. 비공개 부모 공간, 거주·개인 공간, 시설 보안 형상, 이름·IFC 속성·사진 원문이 공개 GLB와 묶음에 남지 않았는지 사람이 확인한다.
6. 다른 검토자가 초안을 승인하고 새 자료판/자산판이 동시에 공개됐는지 파일 SHA와 공개 API로 확인한다.

## 기기·사용자 검사

실제 데스크톱/저사양 노트북/Android Chrome/iOS Safari를 각각 기록한다. 전체 부지 첫 화면, 선택/검색/3D·2D·문자 이동, 카메라 취소, 라벨 가림, 44px/키보드/스크린리더, 동작 줄이기, PNG/공유 링크, 온라인→오프라인→복구를 확인한다. 모바일 viewport 자동 검사를 실제 터치 검사로 표기하지 않는다.

성능은 각 기기에서 시작 60초 후 FPS·프레임 P95·CPU 렌더·그리기 호출·활성 삼각형·메모리를 기록한다. 기본 WebGL과 후보 WebGPU/압축을 같은 장면·해상도·카메라에서 비교한다. 최소 30분 관찰 및 건물 100회 선택/LOD 왕복/캠퍼스 전환/초기화 후 메쉬·텍스처·자산 상주량이 지속 증가하는지 확인한다. CPU 렌더 시간을 GPU 시간으로 보고하지 않는다.

VR은 실제 헤드셋에서 텔레포트/연속 이동, 스냅/연속 회전, 미터 크기, 컨트롤러, 눈높이, UI 가독성, 종료 후 이전 시점 복구, 멀미 여부를 확인한다. 기기 pose를 설정 눈높이로 강제 변경하지 않는다.

AR은 검수된 공개 앵커에서 실제 hit-test로 각 기준점과 독립 검수점을 캡처한다. 스케일을 임의 보정하지 않고 고정 스케일 회전/이동으로 정합한다. 수평·수직 오차가 통과하기 전 콘텐츠를 숨기며 추적 손실/reference-space 변경 후 재캡처·재검수한다. GPS 단독으로 층·호실·문 위치를 확정하지 않는다.

## 캠퍼스·운영·비용

추가 캠퍼스는 새 campusId와 독립 원점·경계·고도·공개 출처·공간 ID·자산판을 등록한다. 동일 이름/별칭이 다른 캠퍼스 선택에 영향을 주지 않는지, 제한 역할의 조회/편집/승인/복구가 자기 캠퍼스만 접근하는지 확인한다. 실제 두 번째 캠퍼스 자료 없이 합성 fixture를 실캠퍼스 인수로 보고하지 않는다.

자료 소유자, 제작자, 검토자, 운영자와 변경/만료/오류 대응 책임을 지정한다. 최초 모델 제작·재검수 시간, 자산 및 DB 증가량, 백업/복구 시간, 호스팅 전송량, AI 호출 비용/제한, 실기기 검사 시간을 실제 견적과 사용량으로 작성한다. 요금이나 학교 운영시간을 추정 값으로 채우지 않는다. 작은 공개판부터 승인·배포·복구 증거를 쌓고 캠퍼스/층/운영 연동을 추가한다.
