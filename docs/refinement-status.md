# 확장 버전 3D 고도화 42개 항목 반영표

기준일: 2026-10-07. 기존 녹색·베이지 전체 화면과 경기캠퍼스 전체 부지, 16개 기존 모델, 영구 공간 ID, 자료 검토·승인·공개·복구 흐름을 유지한다. 구현된 기능과 실제 학교 자료·현장·실기기 인수는 구분한다. 학교 자료가 없는 항목은 입력 계약과 기능을 구현하되 미확보 상태를 표시한다.

|---|---|---|---|
| 1 | 전체 부지 우선 | 기본 외곽·지형·16개 대체 형상 먼저 표시, 전체 부지 카메라 | 실제 토지·시설 범위 검수 |
| 2 | 목적별 안내 | 방문자·재학생·시설 검토 프리셋 | 목적별 사용자 평가 |
| 3 | 경계 의미 | 안내·법적·계획·지적 경계별 자료/선/범례, 미확보 표시 | 법적·지적 경계 미확보 |

| 5 | 항목별 정확도 | 이름·위치·회전·높이·외관·내부·운영 근거 표시 | 항목별 현장 검수 |
