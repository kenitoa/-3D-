# 확장 기획 32개 항목 반영 현황

기준일: 2026-10-07. 기존 한신대학교 경기캠퍼스 전체 조감도와 16개 모델을 유지하면서 등록·검증·탐색·관리·공개·복구 경로를 연결했다. 아래 표는 대화에서 승인한 32개 항목의 원래 번호와 확장 단계 범위를 유지한다. 후속 IFC·AR·근거 AI·불변 자산 묶음의 구현 상태는 [42개 고도화 항목](refinement-status.md)을 함께 따른다. 구현 구조와 외부 자료 확보 여부를 분리한다. **공식 지도 표식은 측량 성과가 아니며, 추정 부지 안내 영역은 법적 소유 경계가 아니다.**

“구현”은 해당 기능의 코드·화면·데이터 계약이 있다는 뜻이다. 검증 열은 그 동작을 검사하는 파일이며, 전체 최종 실행 결과·브라우저 기록은 [validation.md](validation.md)에 기록한다. 합성 경로·GLB·두 번째 캠퍼스 fixture를 사용한 검사는 실제 학교 자료나 현장 이용 검증을 뜻하지 않는다.

## 실행과 관리자 접근

플랫폼 서버는 루트 `start.cmd` 또는 `npm run dev`로 시작한다. 기본 사용자 주소는 `http://127.0.0.1:8765/`, 관리자 주소는 `http://127.0.0.1:8765/admin.html`이다. 관리자 계정은 `npm run admin:create`로 직접 만든다. 비밀번호 입력을 숨기며 최소 12자를 요구한다. 기본 관리자 계정은 없다. 환경 변수·HTTPS·허용 출처·영속 DB·온라인 백업·컨테이너 명령은 [deployment.md](deployment.md)를 따른다. 정적 배포만으로 서버 관리/API 저장 기능이 활성화되지는 않는다.

## 외부 선행 자료와 완료 판정

현장 기능을 실제 서비스로 확인하려면 법적 경계와 측량 좌표, 실내 평면·출입구·통행/접근성 조사, 공식 공간명·운영/행사/공사·번역 자료, 실제 정밀 모델과 사용권, 학교 공급자 계약 및 책임부서/운영 권한이 필요하다. 자료가 들어오면 출처·좌표·단위·기준일·확인 상태를 등록하고 검증·검토·승인·공개판 절차를 거친다.

실제 학교 자료·API·기기·이용자를 확보하지 못한 항목은 기능 구조가 구현돼 있어도 그 현장 완료 조건이 충족됐다고 표현하지 않는다. 미확보 자료를 샘플 운영시간·임의 호실·가짜 센서·가짜 다른 학교 데이터로 채우지 않는다. 정확한 도메인 API와 공개/개인 자료 계약은 [data-contract.md](data-contract.md)에 기록한다.
