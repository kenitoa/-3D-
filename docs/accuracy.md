# 표현 범위와 정확성

## 기준

대상은 한신대학교 경기캠퍼스(경기도 오산시 한신대길 137)이다. 기준일은 2026-10-07이며, 자료의 확인일과 원자료 작성일은 다를 수 있다. 공식 캠퍼스투어의 공개 지도 마커는 학교가 안내한 위치이지 측량된 건물 중심점이나 footprint가 아니다.

공통 좌표는 WGS84 지역 미터 투영의 동(E)·북(N)이다. 표시 좌표는 `x=E/10`, `z=-N/10`, 기본 고도는 `y=상대고도(m)/10`이며 오른손 좌표계를 쓴다. 평면 화면에서 동쪽은 오른쪽, 북쪽은 위쪽이다. 카메라 방위침은 실제 view matrix에서 계산한다. 투시 화면에는 고정 인쇄 축척을 표시하지 않고, 정사영 화면에서 viewport 폭과 카메라 범위에 따라 거리 막대를 계산한다.

## 경계 종류

- **캠퍼스 안내 영역:** 지도와 모델 자료에서 유도한 표시용 범위. 추정 경계는 점선으로 표현한다.
- **도시계획시설 경계:** 공적 고시 도면과 최신 변경 내역을 대조해야 한다.
- **필지·소유 경계:** 지적·소유 자료를 별도로 확인해야 한다.
- **주변 표현 범위:** 진입 도로와 주변 지형을 설명하는 배경이다.

안내 영역을 법적 소유 경계로 주장하지 않는다. 오산시 고시 제2021-54호 존재는 확인했으나 첨부 경계 좌표·최신 변경·소유 관계는 확인하지 않았다. `190,636㎡` 및 주차 `457대`는 기존 요약 자료의 집계 범위를 확인하지 못해 현재 화면의 확정 수치로 사용하지 않는다. 폴리곤을 이 값에 강제 맞추지 않는다.

## 실제 확보한 자료와 한계

1. 공식 웹사이트의 15개 건물명·안내 마커를 추출했다. 새롬터 등 공식 마커가 없는 시설은 다른 안내 근거 또는 기존 모델에서 유도하며 추정 상태를 유지한다.
2. 기존 2026-05-11 OSM 도로 51개·보행로 58개의 반올림된 좌표를 원래 변환의 역변환으로 복원한다. 원본 node ID, 도로 폭, 최근 변경, 접근 가능 여부는 미확인이다. 짧은 연결로와 계단은 길이만으로 제거하지 않는다.
3. 학교 공식 모집요강의 캠퍼스 안내 삽화는 시설 위치·형상 참고 자료다. 정사영상이나 측량도면이 아니므로 그림에서 유도한 외곽·방향은 추정이다.
4. 기존 7×7 SRTM90m 고도는 정밀 DEM이 아니다. 산능선·계곡의 예술 보정은 제거했고 지반 패드는 표시를 위한 추정 평탄화다. 기본 1×, 선택한 지형 강조 배수와 상태를 표시한다.
5. 기존 16개 외관의 세부 조형과 내부 평면을 보존한다. 높이, 창 수, 부속 시설 치수, 층별 원도면 정확성을 실측 확인했다고 주장하지 않는다.

## 등록 오차 검토

공식 안내 삽화와 지리 마커의 등록 RMS는 약 **64.84m**다. 삽화는 비정사영 조감 그림이며 시설 외곽은 실측 자료가 아니다. 건물과 관찰 시설 구획을 포함한 표시 안내 영역은 **149,181.50㎡**로 계산되며 학교의 법적 부지 면적을 의미하지 않는다.

기존 모델 앵커를 네 공식 안내 마커에 맞춘 affine 변환을 나머지 11개 마커로 독립 검토했을 때 RMS 약 123.59m, 최대 약 279.82m였다. 이는 기존 수작업 배치가 공식 안내 위치와 크게 달랐다는 증거이며 측량 정확도를 의미하지 않는다. 새 건물 위치에는 해당 공식 마커의 직접 투영을 사용한다. 지형·기존 형상·삽화 정합의 오차는 여전히 자료 한계로 남는다.

최종 기계 판독 기록은 `evidence/spatial-verification.json`, 자료 출처는 `evidence/source-manifest.json`과 `src/data/site-plan.js`를 확인한다. 추가 도면·정밀 지형·현장 사진을 확보하면 원자료를 변경하고 `scripts/build-site-plan.mjs`로 재생성한 뒤 독립 기준점과 현장 검토를 다시 수행한다.

## 라이선스와 배포

모델 정렬 기준은 복합 건축 덩어리의 추정 범위 중심이다. 단일 대표 동의 폭을 전체 단지 폭으로 오인하지 않으며, 추정 외곽에 들어가는 공통 배율로 기존 비례를 보존한다. 이 기준을 공식 안내 마커에 맞추는 것은 실측 중심·치수 확인과 다르다.

OSM 및 그 파생 공간 데이터의 출처는 © OpenStreetMap contributors, ODbL 1.0이다. 화면과 내보낸 이미지에 출처를 표시한다. 학교 사진·모집요강 원문과 원본 지도 페이지 이미지는 검토용 로컬 파일로만 보관하며 정적 배포에 포함하지 않는다. 사진을 모델 텍스처로 복제하지 않는다.

자동 데이터·렌더·브라우저 검증은 현장 측량, 학교 시설 담당자의 확인, 실제 보행 접근성 검증을 대신하지 않는다.
