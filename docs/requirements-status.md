# 기획 25개 항목 반영 현황

기존 전체 화면·시각 언어·16개 상세 모델·내부도를 보존하면서 아래 기능을 반영했다. **프로그램의 반영과 실측 자료 확보를 구분한다.** 검증 결과는 `validation.md`, 자료별 한계는 `accuracy.md`를 따른다.

법적 경계와 정밀 치수는 외부 자료 확보가 필요하다. `Miss and add.md`에 후속 자료를 기록했다. 새 자료를 반영할 때 출처·오차·건물 포함·면적·진입구와 실제 화면을 다시 검사한다.

PNG는 현재 레이어·시점과 함께 이름·북쪽·평면 축척·추정 경계 설명·OSM 출처를 담는다. 학교 원문 PDF·HTML·삽화·사진은 정적 배포에서 제외한다.
